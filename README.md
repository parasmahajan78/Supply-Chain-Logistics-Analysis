# 🚚 SUPPLY CHAIN & LOGISTICS ANALYTICS DASHBOARD

> **End-to-end data analytics project using MySQL, Excel, and Power BI to analyze supply chain performance, inventory, shipments, suppliers, customers, revenue, and profitability.**

---

## 📌 PROJECT OVERVIEW

This project analyzes supply chain and logistics data to identify business insights across **suppliers, inventory, shipments, customers, revenue, profit, lead time, and order performance**.

The project follows an end-to-end analytics workflow:

**MySQL → SQL Analysis → Excel Data Cleaning → Power BI Data Visualization → Business Insights**

The objective was to transform raw supply chain data into an interactive dashboard that helps monitor operational efficiency, logistics performance, inventory, revenue, and profitability.

## 🔄 PROJECT WORKFLOW

### 1️⃣ SQL ANALYSIS — MYSQL

Used MySQL to analyze supply chain and logistics data and extract meaningful business information.

### Key Analysis Areas

- Supplier performance
- Inventory analysis
- Customer revenue
- Shipment performance
- Order performance
- Lead-time analysis
- Revenue and profit analysis
- Carrier performance
- Delivery delays

SQL analysis helped prepare the data and identify important operational and financial trends.

---

### 2️⃣ DATA CLEANING — EXCEL

The data was cleaned and prepared in Excel before creating the Power BI dashboard.

### Data Preparation

- Cleaned raw supply chain data
- Formatted data fields
- Checked data consistency
- Organized numerical and categorical data
- Prepared data for visualization
- Ensured data was suitable for Power BI analysis
